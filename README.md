# Pipline-automatico-med-Pami

📊 Construí un pipeline automatizado con datos de medicamentos de PAMI (2.000 registros).

El problema: ¿cuánto ahorra en promedio un afiliado según la cobertura de cada medicamento?

Cómo lo resolví:
▪️ Dataset en Google Sheets
▪️ n8n Cloud: workflow automatizado con lógica de cálculo en JavaScript
▪️ Resultados en Sheets, conectados a un dashboard en Looker Studio

Lo que aprendí: automatizar con triggers, validar para no duplicar registros y por qué el promedio simple puede engañar cuando los precios son tan dispares.
